### 中文版

# RandomRecipes (随机合成表)

**RandomRecipes** 是一款为 Minecraft 带来全新生存体验的模组。它会在游戏运行期间，按照指定的时间间隔（默认 5 分钟），自动打乱游戏内**所有**的合成配方——包括原版内容以及其他模组添加的合成表。

你将不再能依赖背熟的配方表，每一次合成都是一次全新的探索与惊喜！

## 特性

·       **全局配方打乱**：不仅打乱原版合成，同样兼容并打乱其他模组的合成配方。

·       **动态刷新**：每隔指定时间（默认 5 分钟）自动重新随机打乱一次所有配方。

·       **高度兼容**：基于 Forge 平台开发，致力于与现有模组生态无缝协作。

## ️ 配置说明

你可以通过修改配置文件来调整打乱配方的时间间隔：

| 配置项             | 默认值 | 说明                         |
| --------------- | --- | -------------------------- |
| intervalMinutes | 5   | 配方打乱的时间间隔（单位：分钟）。默认 5 分钟）。 |

**提示**：修改配置后需要重新加载世界才能生效。

## 安装方法

1.      确保你已经安装了正确版本的 **Minecraft Forge**。

2.      将下载的 RandomRecipes-x.x.x.jar 文件放入游戏目录下的 mods 文件夹中。

3.      启动游戏，享受随机合成的乐趣！

### English Version

# RandomRecipes

**RandomRecipes** is a Minecraft mod that brings a brand-new survival experience. During gameplay, it automatically shuffles **all** crafting recipes—including vanilla items and those added by other mods—at a specified interval (default: 5 minutes).

Say goodbye to memorized recipe books! Every craft is a new adventure.

## Features

·       **Global Recipe Shuffle**: Shuffles not only vanilla recipes but also seamlessly integrates with and shuffles recipes from other mods.

·       **Dynamic Refresh**: Automatically re-shuffles all recipes at a set interval (default: 5 minutes).

·       **High Compatibility**: Built for Forge, designed to work smoothly with the existing mod ecosystem.

## ️ Configuration

You can adjust the shuffle interval by modifying the configuration file:

| Option          | Default | Description                                                                   |
| --------------- | ------- | ----------------------------------------------------------------------------- |
| intervalMinutes | 5       | The time interval between recipe shuffles (in minutes). Default is 5 minutes. |

**Note**: A game restart or world reload is required for configuration changes to take effect.

## Installation

1.      Make sure you have the correct version of **Minecraft Forge** installed.

2.      Drop the RandomRecipes-x.x.x.jar file into your mods folder.

3.      Launch the game and enjoy the chaos!
